    How to improve it

      Need a strong one?

      This uses your browser's secure random generator.

      Estimates assume an attacker who has stolen a hashed password database and tries 10 billion guesses per second (a fast hash on a GPU rig). Real results vary with the hashing method. The check uses a short list of common passwords, not a full dictionary, so it can overestimate passwords built from ordinary words. Treat the result as a learning aid, not a guarantee. A copied password is cleared from the clipboard after 30 seconds when the browser allows it.
